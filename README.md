# 🧠 Second Brain - My AI JARVIS by Bharat

> My private, offline-first life OS that never forgets an idea.

**Live Repo:** `bharathlakshminaryana-byte/second-brain`

### 🚀 What is this?
As a developer + DJ, I get 100+ ideas daily. I needed a system that is 100% mine - no cloud, no API, no fees. So I built Second Brain - a Python app that captures text & voice ideas into a local Markdown vault with auto daily summaries.

### ✨ Features
- **Instant Capture:** GUI to save any thought in 2 seconds
- **Voice Brain:** Records voice notes as `.wav` for future AI transcription
- **Daily Auto-Summary:** Creates `summary-2026-09-08.md` every day via batch script
- **Markdown Vault:** All thoughts stored in `brain.md` - forever searchable
- **Offline & Private:** Zero internet needed. Your data = your laptop
- **EXE Ready:** Built with PyInstaller - runs as `SecondBrain-Bharat.exe`

### 🛠️ Tech Stack
`Python` `Tkinter` `Markdown` `Batch Automation` `PyInstaller` `Local-First Design`
